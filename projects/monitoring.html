    ACTIVE PRODUCTION Enterprise Network & Telemetry

    Integrated Monitoring Systems

    A large-scale telemetry monitoring system designed to keep national infrastructure reliable. It covers Korlantas ERI, EAVIS analytics, distributed ETLE sites, and real-time server cluster health.

    Project Overview

    This project focuses on designing and deploying an advanced telemetry monitoring system for large-scale networks and server infrastructures. The system prevents downtime by detecting early issues in network traffic, LVM storage capacity, and server physical health.

    The core setup combines Paessler PRTG Network Monitor (Core & Remote Probe) to handle thousands of sensors, and Grafana for high-level visual dashboards. It monitors several key operational systems:

    • Korlantas ERI (Electronic Registration and Identification): Monitors node availability, latency, and network throughput across central and regional sites.
    • EAVIS & ETLE Infrastructure: Tracks real-time status of flashlamp devices, site controllers, and distributed data pipelines.
    • Cluster & Bare-Metal Server Health: Monitors hardware resources (CPU, RAM, RAID / SSD DWPD endurance, thermal sensors) using SNMP v3 and Node Exporter.

    Key Implementation Highlights

    • 📡 Multi-Probe PRTG Deployment

      Configured PRTG Core and Remote Probes to manage 5,000+ to 10,000+ active sensors efficiently without overloading the main engine.

    • 📊 Grafana Dashboards

      Transformed raw logs and metrics into clean, easy-to-read executive dashboards for both technical teams and management.

    • ⚙️ Custom Telemetry & Alerts

      Set up automatic alerts based on custom thresholds to resolve node issues before public services are affected.

    • 🔒 Air-Gapped & Secure Setup

      Handled offline installation and package transfers via Secure Copy (SCP) in highly restricted network environments.
